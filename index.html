Put it in your spreadsheet

After publishing, this page fills in its own URL. Include your repository path, or use your custom domain.

For a numeric rating in A2:

=IF(ISNUMBER(A2),IMAGE("https://YOUR-USERNAME.github.io/YOUR-REPO/stars/"&SUBSTITUTE(TEXT(ROUND(MAX(0,MIN(5,A2)),2),"0.00"),",",".")&".png"),"")

For the average of the numeric ratings in Ratings!B2:B:

=IF(COUNT(Ratings!B2:B)=0,"",IMAGE("https://YOUR-USERNAME.github.io/YOUR-REPO/stars/"&SUBSTITUTE(TEXT(ROUND(MAX(0,MIN(5,AVERAGE(Ratings!B2:B))),2),"0.00"),",",".")&".png"))

Formulas round to two decimals, limit ratings to 0–5, and leave empty inputs blank. Adjust the row height and column width for the stars. If your sheet uses semicolons as argument separators, replace separators outside quotation marks; leave quoted text unchanged.

Publish on GitHub Pages

  1. Put this project’s contents in a GitHub repository, including stars/ and .nojekyll. Keep index.html at the repository root.
  2. Open Settings → Pages. Choose Deploy from a branch, then main and /(root). Save.
  3. Wait for the deployment, open your published site, and copy the formula above into Google Sheets.

File pattern: stars/0.00.png through stars/5.00.png. Always include two decimal places, even for whole numbers.

All 501 images are included. Hosting needs no build step, server, API key, or Apps Script.

PNGs are 580 × 116 pixels with antialiased edges. Fractional fill measures horizontal width, not the star’s area.
Reference: Google Sheets IMAGE documentation · GitHub Pages publishing guide
